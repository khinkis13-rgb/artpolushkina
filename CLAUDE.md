# artpolushkina.com — сайт художницы Марии Полушкиной

Клиентский проект Дмитрия (Маша Полушкина, Telegram `@m_polushkina`, id 786726716).
Просьбы по сайту приходят от неё в Telegram.

## Как устроено

- **Хостинг:** GitHub Pages из корня ветки `main` репозитория
  `khinkis13-rgb/artpolushkina` (до 30.10.2026 назывался `-Users-dmitrykhinkis-Documents-CURSOR-FLAG-ART`),
  домен — файл `CNAME`.
  Сборки нет: что запушено в `main`, то через ~1 мин на сайте.
- **artpolushkina.ru** и **artpolushkina.art** (RU-CENTER, оплачены до 06.04.2027) — только редирект на .com с сохранением
  пути и `#work-<id>`: репозитории `khinkis13-rgb/artpolushkina-ru` и `-art` на GitHub Pages (JS-редирект в `index.html`/`404.html`),
  DNS — бесплатный DNS-хостинг Selectel (аккаунт Дмитрия 741037, проект My First Project; DNS-master в nic.ru платный),
  у регистратора серверы `a/b/c/d.ns.selectel.ru`: `A @` на 4 адреса GitHub Pages, `CNAME www` на `khinkis13-rgb.github.io.`.
- **`index.html`** — весь сайт (HTML + CSS + JS в одном файле). Данные тянет при загрузке
  из `catalog.json` и `content.json`; если они не загрузились — берёт запасные `W_FB` / `CT_FB`.
- **Скорость загрузки** (02.11.2026): шрифты свои — `site/fonts/*.woff2` + `@font-face` в начале `<style>` (Google Fonts
  блокировал первую отрисовку на ~1–3 с); ролик заставки ставится только после `load` (до этого кадр-заглушка), чтобы
  6–18 МБ видео не отнимали канал у шрифтов и картинок; картинки публикаций — до ~800×600 (админка ужимает их до 1000 px).
- **`catalog.json`** — работы: `id`, `t`/`te` (название ru/en), `m`/`me` (техника),
  `s` (размер «высота×ширина» в см), `y` (год), `p` (цена ₽), `media` (`[{type:'img'|'vid', path}]`).
  Без `media` берётся `site/images/work-<id>.jpg`.
- **`content.json`** — биография, выставки, публикации, контакты.
- **`site/images/`** — все живые картинки (работы `work-*.jpg`, публикации `pub-*.jpg`, фото художницы).
- **`admin.html`** — админка (artpolushkina.com/admin.html). Вход по GitHub fine-grained токену,
  правки коммитит прямо в `main` через GitHub API (отсюда сотни коммитов «Обновлена работа #N»).
  Картинки грузит в `site/images/`, видео — в `site/videos/`.

## Как менять

- Тексты, цены, работы — через админку или правкой JSON.
- Перед правкой всегда `git pull`: админка коммитит в `main` в обход локальной копии.
- Проверка локально: `python3 -m http.server 8765` в корне → http://localhost:8765/.
- Каталог раскладывается по колонкам в JS (`rC` → `catCols`, `catRatio`): картины показываются
  в реальных пропорциях, без обрезки. Не возвращать `aspect-ratio:1` / `object-fit:cover`.

## Шапка и заставка

- **Логотип** вверху слева — подпись Маши с картины (`work-60`), обведённая в вектор и залитая
  «золотой краской»: `site/images/logo-signature.svg`. Исходник более высокого качества — фото подписи от Маши.
- **Заставка** — один ролик за текстом на весь первый экран и волну под ним: картина, фон вокруг, фактура холста,
  море с волнами, провод лампы, рыба и растворения на склейках собраны заранее в видеофайл, рассинхрона фона с картиной нет.
  С 02.11.2026 собирается из **оригинала аниматора** 3840×2160 (`Анимация мультфильм полностью.mp4`, 521 МБ, в репозиторий не
  кладём; первые 6 кадров — до начала ролика). Три ролика, картина в правильных 16:9:
  `site/videos/hero-desktop.mp4` (2808×1728, картина 960×540 с углом в (1341, 549)), `hero-desktop-2x.mp4` (3744×2304,
  картина 1280×720 в (1788, 732); retina и экраны от 2560 — `innerWidth·devicePixelRatio > 2200`) и `hero-phone.mp4`
  (720×2236: квадрат 720 середины кадра во всю ширину, сверху 124 px под шапку), кадры-заглушки `site/images/hero-*-poster.jpg`.
  **Страница** (`heroOne` в `index.html`, таблица `HERO_V`): ставит ролик так, чтобы картина кадра легла ровно на `#heroBox`
  (16:9); по времени ролика (`HERO_SC`) меняет тёмный/светлый текст, подпись со ссылкой на работу, на море — светлый текст
  ниже горизонта (`txSplit`, `HERO_HZ`).
  **Сборщик** — `tools/hero/` (на сайт не влияет): `build.sh <оригинал> <временная папка>` (~1 ч) — мезонин 1920×1080 RGB
  без потерь, затем `build.py` по партитуре `score.py` (сцены, склейки, обрезка картин по шву `CLIP`, фон `BG`, волны, провод).
  Фон вокруг картины не таблица цветов, а сами края картины: полоса у края (медиана по кадрам сцены, только цвета бумаги/стены
  `ref` — рисунок у края пропускается) продолжается наружу всё мягче с расстоянием, по сторонам — строками/столбцами, в углах
  смесь; лист или доска на ровном фоне кадра (`hole` в `BG`) не продолжаются — над и под ними фон; в каждом кадре фон ещё подстраивается под тон бумаги (`drift`: свет в ролике плывёт; медиана по ±3 кадрам, иначе рисунок у края даёт одиночные вспышки фона). Фактура зелёной и синей стены —
  бесшовные плитки из полос у краёв кадра (`texture.py`), волны — полоса горизонта из этого же кадра с бесшовным повтором,
  провод — верхние строки кадра у провода вверх до края экрана, рыба за краями картин — очищенный спрайт и путь из `fish.py` (у края — по видимому хвосту в кадре; уплывающая — поверх картины целиком, её часть в ролике стёрта, гаснет к смене картины; `--fix` — без повторного слежения).
  Снятое заранее (пересчитывать, только если сменится ролик): `assets/borders.npz` (`plates.py`), `assets/fish*` (`fish.py`).
  Склейка — замерший последний кадр сцены вместе с фоном растворяется в новую за 0,6 с; повтор бесшовный. Цвет — в домене
  декодированного ролика, браузерных таблиц и кривой Chrome больше нет. Кадр 2018 оригинала — мусор склейки, заменён на 2019.
  **Грабли:** время кадра n — `n/30+0,001` (склейка 67,267 — кадр 2018,01); после пересборки прогнать кадры на одиночные
  вспышки; локально видео смотреть через сервер с Range (`python3 -m http.server` его не умеет) и менять `?v=` в `HERO_V`.
  Прежний сборщик из ролика 848×464 (растянут по ширине на 2,8 %) и его таблицы — в git-истории (до 02.11.2026).

- **Рыба поверх сайта** (`swimFish` в `index.html`, спрайт `site/images/swim-fish.webp` — вырезан из `tools/hero/assets/fish-exit.png`):
  когда заставка прокручена, раз в 10–24 с заплывает с края экрана, проходит над 1–2 видимыми картинами (`.ci`, `.ap-ring`, `.pc img`)
  и уплывает за другой край; курсор или палец рядом — пугается и уходит быстрее. Хвост — отдельный кусок спрайта, машет вокруг
  стыка (48 из 312 px). Под шапкой (z-index 80 < 100), прячется при открытой карточке и примерке, нет при `prefers-reduced-motion`.
- **Три ролика заставки по очереди** (с 02.11.2026): `hero` — аниматора (выше), `hero2` и `hero3` — собраны нами из фото работ
  сборщиком `tools/anim/` (на сайт не влияет). Страница (`HERO_REELS` в `index.html`) на каждом заходе берёт следующий
  (счётчик `mp_reel` в `localStorage`, первый заход — ролик аниматора), `?reel=1..3` — показать нужный. Раскладка та же
  (`heroV`: `site/videos/<имя>-desktop|desktop-2x|phone|phone-lite.mp4`, заглушки `site/images/<имя>-*-poster.jpg`).
  `hero2`: 57 «Поплыли!», 66 CHEERS!, 56 «Последняя капля», 26 «Она ждала дождя», 58 «Отбрось всё!»;
  `hero3`: 64 «В предвкушении», 20 «You can leave your hat on», 73 «Через монокль», 68 «В унисон».
  **Сборщик:** `lib.py` — договор сцены и общее (геометрия как `HERO_V`, холст, спрайты, линии, кодирование); каждая сцена —
  `s<id>.py` (разбор фото на слои + движение, кадр 0 и последний — сама картина), проверка `python3 s<id>.py <папка> d 0,90`;
  ролик — `python3 reel.py hero2 s57,s66,s56,s26,s58 <d|d2|m|m1> <out.mp4>` (из `tools/anim`). Пауз нет (просьба Маши):
  неподвижные куски в начале/конце сцены срезаются сами (кэш `.still.json`), хвост сцены перетекает в начало следующей
  за 0,8 с, пока обе движутся; рядом `out.json` — строки для `SC`; у сцен с морем «цвет под роликом» — цвет моря и
  горизонт в `HZ`. Длительность сцены одна на все раскладки — иначе разъедется таблица времён.
  **Грабли:** шум/фактура на большом движущемся поле раздувает ролик в разы (море в s20 гладим); линии, уходящие влево,
  гасить у текстовой колонки (s68); после пересборки менять `?v=` в `heroV`.

## Функции для покупателя (всё в `index.html`)

- **Фильтры** по цене и размеру (`#cPr`, `#cSz`; размер — по большей стороне из `s`, функция `dims`).
- **Избранное** — сердечки на карточках, хранится в `localStorage` (`mp_fav`); плашка внизу
  «Написать о работах» открывает личку Маши со списком (`askFav` → `tgMsg`).
- **Ссылка на работу** — `artpolushkina.com/#work-<id>` сразу открывает карточку; кнопка «Поделиться».
- **«Купить»** открывает `t.me/<telegramDm>?text=…` с названием, №, размером и ценой; текст
  дублируется в буфер обмена на случай, если Telegram его не подставит.
- **Примерка на стене** (`tryOpen`): пример интерьера с диваном 2 м в реальном масштабе
  (рисуется в canvas, `drawRoom`) или своё фото; масштаб по линейке — линия вдоль предмета
  известной длины. Фото никуда не загружается. «Сохранить» / «Отправить художнице» —
  готовая картинка с подписью (на телефоне через системное «Поделиться»).
